## 一、文件总览

`data/` 目录**只有两个文件**：

| 路径 | 说明 |
|---|---|
| `data/termite_gas_measurements.csv` | **全部实测数据**（0–24 h 分析窗口的 15 626 个样本，一行一个样本） |
| `data/README.md` | 英文数据说明（本文件为其中文版） |

CSV 是唯一发布的数据文件。用纯文本存放，GitHub 上可直接 diff、可读，Excel / R / MATLAB / Python 均可直接打开，无需额外阅读器。

**规模**：1 行表头 + **15 626 数据行 × 6 列**。文件约 0.72 MB，编码 **UTF-8 带 BOM**（便于中文 Windows 下 Excel 正确显示表头），换行符 LF。

文件内容就是论文的 **0–24 h 分析窗口**，不含其他区段：每个舱前 24 h 的分钟级记录，即论文分析的全部数据。没有需要额外解释的窗后尾部，论文引用的极值（CO₂ 342–4 684 ppm、CH₄ 0–310 ppm）也正是本文件自身的极值。

覆盖 **8 个白蚁舱 + 3 个空白对照 = 11 条时间序列**，跨 **3 个独立采集批次**（Batch 1 / 2 / 3）。同一批次内各舱并行采样，历时轴完全对齐。

```
CO2 (ppm),Temperature (°C),Relative humidity (%RH),CH4 (ppm),Timestamp,Chamber (N)
531,21.54,61.56,0,08-24 12:46,Batch 1 · Blank (0)
534,21.46,61.13,0,08-24 12:47,Batch 1 · Blank (0)
...
965,24.00,75.76,0,08-24 12:46,Batch 1 · 310
...
```

## 二、字段定义

列名全英文，术语取自论文：`CO2` / `Temperature` / `Relative humidity` 见 Table 1，`Chamber (N)` 见 Table 5。

| # | 列名 | 类型 | 单位 | 含义 |
|---|---|---|---|---|
| 1 | `CO2 (ppm)` | 整数 | ppm | **CO₂ 浓度** —— 核心因变量 |
| 2 | `Temperature (°C)` | 浮点 | ℃ | 舱内温度 |
| 3 | `Relative humidity (%RH)` | 浮点 | %RH | 相对湿度（用于密封性 / 存活判据） |
| 4 | `CH4 (ppm)` | 整数 | ppm | **CH₄ 通道读数**（MOx 模块），解释边界见第四节第 7 条 |
| 5 | `Timestamp` | 字符串 | `MM-DD HH:MM` | 采集时间；**不含年份**（见第四节第 4 条） |
| 6 | `Chamber (N)` | 字符串 | — | 该行属于哪个舱；**`N` 即白蚁数量** |

### `Chamber (N)` 列

数据原本是「每批次一个工作簿、每舱一个工作表」，同批次各舱并行采样。CSV 承载不了工作表，因此把舱信息放进一列，取值**与论文 Table 5 完全一致**：

| 取值 | 批次 | `N` | 空白对照？ |
|---|---|---|---|
| `Batch 1 · 310` | 1 | 310 | 否 |
| `Batch 1 · Blank (0)` | 1 | 0 | **是** |
| `Batch 2 · 105` … `Batch 2 · 500` | 2 | 105 … 500 | 否 |
| `Batch 3 · 343`、`Batch 3 · 461` | 3 | 343、461 | 否 |

- 分隔符是**中间点 U+00B7**，两侧各一个空格。
- `N = 0` 记作 `Blank (0)`（与论文 Table 4 的 *Condition (N)* 写法一致），代表空白对照，共 3 个，每批次 1 个。
- 剂量轴 *x* 为白蚁数量 **N**（105 … 500）。

### 行序与历时

- **每一行都在分析窗口内。** 每个舱只贡献前 24 h（`h ≤ 24`）：批次 1–2 每舱 **1 420 行**，批次 3 每舱 **1 422 行**（1 420 × 8 + 1 422 × 3 = **15 626**）。24 h 之后的记录未发布，因此「文件行数」与「论文窗口」是同一个东西。
- 一行一个样本，按**采集顺序**排列；每批次内空白对照在最前。
- 同批次各舱共用一条历时轴；**三批次时间互不重叠**，不可跨批次对齐时间轴。
- 历时小时数不是列，需自行推导：`h = (t − t₀)/3600`，`t₀` 为同一 `Chamber (N)` 的首个样本，范围 0–24。

### 读取方式

直接用 pandas 读即可，没有任何需要跳过的行：

```python
import pandas as pd

df = pd.read_csv("termite_gas_measurements.csv", encoding="utf-8-sig")

# 把 "Batch 1 · 310" 拆成批次与条件，并还原 N
parts = df["Chamber (N)"].str.partition(" \u00b7 ")
df["batch"], df["condition"] = parts[0].str.strip(), parts[2].str.strip()
df["N"] = pd.to_numeric(
    df["condition"].where(df["condition"] != "Blank (0)", "0"))
df["is_blank"] = df["N"] == 0

# 时间无年份：先补一个假设年，再逐舱求历时。
# 取模 86400 用于抵消跨午夜时解析结果回退约 24 h 的问题。
df["t"] = pd.to_datetime("2025-" + df["Timestamp"], format="%Y-%m-%d %H:%M")
df["h"] = (df.groupby("Chamber (N)", sort=False)["t"]
             .transform(lambda t: (t.diff().dt.total_seconds().fillna(0)
                                   % 86400).cumsum() / 3600))
```

`src/pipeline.py::load_long()` 在此基础上再返回论文所用的去尖峰、重采样序列。

## 四、使用注意事项（重要）

1. **采样间隔**：名义 1 分钟，实测每个舱缺失约 **1.3–1.5 %** 的分钟点（多舱轮询丢点），行数 ≠ 分钟数。做时间导数前请先重采样或按 `h` 插值。
2. **文件在设计上止于分析窗口。** 每个舱的记录都到 `h = 24` 为止，没有「窗后尾部」需要丢弃。实际采集时长更长（每舱 48.4–51.8 h），但 24 h 之后白蚁可能已受胁迫或死亡，这部分不在本论文范围内、也未发布。窗口即全部数据。
3. **数值为原始值、未去尖峰**：极值均在合理量程内（CO₂ 342–4 684 ppm、CH₄ 0–310 ppm、温度 20.0–32.1 ℃、湿度 48.9–94.6 %RH）。需要严格去尖峰时请用 `pipeline.despike`（7 点滚动 MAD，k = 6）；论文用的预处理在 `src/pipeline.py`，可自行修改后重跑。
4. **`Timestamp` 不含年份 —— 但 Excel 打开时会补一个年份**。时间戳只有月、日、时、分。Excel 的 CSV 导入会把 `08-24 12:46` 当日期解析，再按本机格式显示成 `2026/8/24 12:46`；**年份不在文件里**。这是电子表格导入时的转换，纯 CSV 无法阻止。所有时长请用 `h`，不要依赖绝对日期。（原始采集工作簿里该格是文本，Excel 显示时不带年，所以在 Excel 里打开会与发布的 CSV 看起来不同。）
5. **空白对照必须按批次配对**：净积累 = `ΔCO₂(白蚁舱) − ΔCO₂(同批次空白舱)`。三个空白**不可互换、不可合并、不可取平均** —— 其 24 h 漂移为 +34.3、−5.5、+11.5 ppm，符号都不一致。
6. **批次效应真实存在**：批次 1、3 比批次 2 模型预测低 11.9–21.4 %。建议把批次作为随机/固定效应，或分别报告批内与批间结果。
7. **CH₄ 通道是 MOx 读数，不是甲烷通量**：舱内偏相关显示其与温度强相关（偏 r = 0.55）；空白舱既干燥又无 CH₄，湿度与「有无白蚁」完全混杂。本数据只支持**舱间排序**结论。
8. **三个批次共用一套标定**：数据已是标定后数据。标定文件与原始标定数据不在本仓库内，**以索要方式提供**，见 `calibration/README.md`。
